# Blazor Blueprint Documentation Fallback

Use the installed Blazor Blueprint MCP first for component APIs, setup, patterns, icons, and version-specific guidance.

When the MCP is unavailable, returns an error, or lacks the required detail, consult the official Blazor Blueprint LLMS documentation:

- Index: https://blazorblueprintui.com/llms/index.txt
- Component documentation: https://blazorblueprintui.com/llms/components/<component>.txt
- Primitive documentation: https://blazorblueprintui.com/llms/primitives/<primitive>.txt
- Navigation blueprints: https://blazorblueprintui.com/llms/blueprints/navigation.txt

Do not guess component parameters when either documentation source can provide the exact API. Keep user-facing UI text in Spanish and technical artifacts in English, following the repository instructions.
